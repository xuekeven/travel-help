## 模块六：候补订单 · 数据同步 API

### TC-017 同步接口 Token 验证

**前置条件**：服务已启动，`.env` 中 `EXTENSION_SYNC_TOKEN=test-token-123`  

**操作步骤 A**（正确 Token）：
```bash
curl -X POST http://localhost:3000/api/waitlist/sync \
  -H "Content-Type: application/json" \
  -H "x-sync-token: test-token-123" \
  -d '{"orders":[{"orderNo":"TEST001","departureDate":"2026-08-01","fromStation":"北京南站","toStation":"天津南站","trainNumbers":["G1"],"seatType":"二等座","ticketCount":1,"price":54.5,"departureTime":"08:00","arrivalTime":"08:31","status":"候补中","rawData":{}}]}'
```

**预期结果 A**：`{"success":true,"count":1}`

**操作步骤 B**（错误 Token）：
```bash
curl -X POST http://localhost:3000/api/waitlist/sync \
  -H "Content-Type: application/json" \
  -H "x-sync-token: wrong-token" \
  -d '{"orders":[]}'
```

**预期结果 B**：HTTP 401，`{"error":"Unauthorized"}`

### TC-018 重复同步同一订单（Upsert）

**前置条件**：TC-017 操作步骤 A 已成功执行（`TEST001` 已入库），此时状态为"候补中"  

**操作步骤**：
```bash
# 再次 POST，状态改为"已成功"

  -H "Content-Type: application/json" \
  -H "x-sync-token: test-token-123" \
  -d '{"orders":[{"orderNo":"TEST001","departureDate":"2026-08-01","fromStation":"北京南站","toStation":"天津南站","trainNumbers":["G1","G3"],"seatType":"二等座","ticketCount":1,"price":54.5,"departureTime":"08:00","arrivalTime":"08:31","status":"已成功","rawData":{}}]}'
```

**预期结果**：
- 返回 `{"success":true,"count":1}`
- 数据库中 `TEST001` 仍只有**一条记录**（不重复插入）
- 该记录的 `status` 变为 `已成功`
- `trainNumbers` 更新为 `["G1","G3"]`
- `synced_at` 更新为当前时间
